This API accepts, stores, proccesses, and returns datasets. The purpose of the endpoint GET /health is to make sure the program responds. The responsability of the endpoint POST /upload is to read and store a csv. The endpoint GET /datasets/{dataset_id} retrieves the dataset with the given id, and returns up to the given limit of rows, while POST /datasets/{dataset_id}/process validates and processes the data based on the given config, returning a processing report.
